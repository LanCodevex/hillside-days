请用 Three.js 制作一个可拖拽旋转、缩放的「山坡上的小屋」微缩场景，输出为单个 HTML 文件，通过 importmap 从 CDN 引入 Three.js 和 OrbitControls，所有模型用代码程序化生成，不加载外部模型。

【场景】
场景搭建在一块圆形草地底座上，底座边缘露出泥土和石头断面，像从山坡上切下来的一块。主体是一栋两层半的欧式乡间小屋：米白灰泥墙、深木色梁柱外露，红褐色陡坡屋顶上有一个小阁楼窗和一根石砌烟囱，烟囱持续冒出缓慢上升、逐渐消散的白色烟团。一楼有带木栏杆的门廊，门廊上放一把摇椅和几盆花；侧墙挂着爬藤，窗台摆着花箱。屋旁有一棵高大的阔叶树，树冠饱满蓬松，由多层团簇组成，留有透光空隙，树下挂一个木秋千。屋前有一条蜿蜒的石子小路、一小块菜园、一根晾衣绳（挂着随风轻摆的白床单），远处有一架缓慢转动的小风车。草地上散落野花，草叶用 InstancedMesh 实现，并随风轻微摆动。

【美术风格】
整体采用日式手绘动画电影的美术风格：温暖、明亮、怀旧但不陈旧。用卡通着色（toon / cel shading）表现三维形体，两到三阶明暗，阴影偏暖紫而不是黑灰。轮廓清晰，不使用粗黑描边。材质以纯色和柔和渐变为主，墙面和屋顶可以带轻微的手绘笔触感。天空是大片饱满的渐变色，飘着体积感强、边缘柔和的积云，云朵缓慢移动。配色以草绿、奶白、红褐屋顶、天蓝为主，强调阳光照在墙面上的暖意。不追求照片写实，不添加做旧滤镜。

【镜头】
默认镜头为三分之四视角，略微俯视，门廊、烟囱、大树和秋千都可见。提供三个镜头预设，点击时平滑过渡（用缓动插值）：
- Overview：全景
- On the porch：贴近门廊摇椅的低机位
- Slow orbit：绕场景缓慢自动环绕
拖拽旋转需限制俯仰角，不能转到底座下方；缩放需限制最近和最远距离。

【时间切换】
提供四个时间预设，切换时天空颜色、太阳光方向/颜色/强度、环境光、雾色全部平滑过渡约 1.5 秒：
- Morning：清晨，偏冷的淡金色
- Summer noon：明亮夏日正午，饱和的蓝天白云
- Golden hour：黄昏，橙粉色天空，长影子
- Starry night：深蓝夜空和星星，屋内窗户透出暖黄灯光，草地上有缓慢飘动、闪烁的萤火虫粒子

【交互】
- 鼠标悬停在窗户、信箱、秋千上时轻微高亮
- 点击窗户弹出一张手账风格的卡片（HTML 覆盖层），写一段关于这间小屋的短文，有关闭按钮
- 点击信箱弹出一封信的卡片

【页面 UI】
左侧是半透明的竖向信息栏，衬线字体：顶部标题「Hillside Days」配一句英文副标题，中间是镜头预设按钮，底部是时间切换按钮，最下方小字提示「Drag to explore · Scroll to zoom」。整体留白充足，精致克制，像一本绘本的扉页。

【技术要求】
- 开启阴影，但控制阴影贴图分辨率，保证在普通笔记本和手机上流畅
- 树冠、草、花大量使用 InstancedMesh
- 代码按模块分段并加中文注释（场景、建筑、植物、天空、光照、交互、UI），方便我逐段修改
- 窗口尺寸变化时自适应
迭代提示词

第一版出来偏低多边形手游风，之后分三轮往宫崎骏动画的方向调整。

第一轮：树和草
把树冠从多面体块改成宫崎骏动画风格：用大量带透明度的叶片贴片（alpha 卡片）或细分更圆润的球团组成，团簇大小有变化。受光面用暖黄绿，背光面用偏蓝的深绿，明暗分界清晰；冠层边缘零散、能透出天空。草地加入深浅不同的大块色斑和噪声变化，加一层随风传播的波浪动画（不是每根草各自独立摆动），再加几丛更高的草和成片的野花团。
第二轮：天空和构图
天空加入 2-3 座巨大、高耸的积雨云，体积感强，底部偏暖灰紫、顶部亮白，缓慢漂移，占据画面上方大约三分之一。补上晾衣绳和随风摆动的白床单；在空旷的草地上加一段矮石墙或木栅栏、一个木水桶和几块垫脚石，让前景有层次。底座下方的浮岛岩体更自然一些，挂几根垂下的藤蔓。
第三轮：光影和后期
加入后期处理（EffectComposer）：轻微 Bloom，让夜晚的窗户灯光、萤火虫和黄昏太阳有柔和辉光；加 SSAO 或接触阴影，增强物体落地感；加一层轻微的暖色调色和暗角。夜晚模式下窗户透出的暖光要投射到门廊和附近草地上，萤火虫数量加倍、更大更亮，并带呼吸式闪烁。注意保持手机端流畅，提供一个低画质开关。
可选的后续优化

还没做或可以继续打磨的方向，想自己试的可以接着用：

修复夜晚树冠过亮 + 树冠体块
1. 修复夜晚树冠过亮：把树冠的三种颜色（uLeafHi / uLeafLit / uLeafShade）加进 TIMES 的每个时间预设里，随时间插值。夜晚用偏暗的蓝绿色，黄昏偏暖橄榄绿。同时检查 fK 除以 uSunRef 的归一化：夜晚月光很弱时，树冠不应该被判定为"满受光"。
2. 树冠改成 4-6 个清晰的大叶团，减少外缘零碎的小团，叶片贴片加大约 30%。叶团之间留出明显的深色阴影缝，背光面更深更蓝，让体块一眼可读。
云和花
1. 积雨云塔改成高大于宽（高约为宽的 1.6-2 倍），其中一座最高的位于默认镜头里小屋的后上方，顶部砧状、亮白，底部暖灰紫。
2. 花朵从小球改成扁平的小花盘（5 片花瓣的圆片或十字交叉面片），大小有变化；每个花团的颜色收敛成一主一辅，靠近花团中心更密、更高。
小池塘
在小路右侧与底座边缘之间的空草地上加一个小池塘：边缘是不规则的石头和芦苇，水面反射天空颜色并有轻微波纹，夜晚倒映星星和萤火虫。池塘边放一块平石头。注意不要和小路、花团、晾衣绳重叠。
